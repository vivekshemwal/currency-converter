# 💱 Currency Converter

A simple web app that converts amounts between different currencies using exchange-rate data. Built with vanilla HTML, CSS, and JavaScript — pick a source and target currency, enter an amount, and get a live-converted result.

---

# Features

- 🔄 Convert between multiple world currencies
- 📊 Uses real-time exchange-rate data
- 🎨 Simple, lightweight interface — no frameworks required
- 📱 Responsive design for desktop and mobile

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vivekshemwal/currency-converter.git
   ```
2. Navigate into the project folder:
   ```bash
   cd currency-converter
   ```
3. Open `index.html` in your browser — no build step or server required.
